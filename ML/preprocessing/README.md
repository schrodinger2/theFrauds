# COMISET — Data Preprocessing & Feature Engineering

## Overview
This section contains the data preprocessing and feature engineering workflow for the COMISET cybersecurity dataset.

## Workflow

1. **Original Preprocessing:** Initial data processing and One-Hot Encoding (OHE).
2. **Column Selection and Analysis:** Removal of selected columns and analysis of fields suitable for feature extraction.
3. **Feature Engineering:** Extraction of meaningful features from selected log fields.

## Notebooks
- `comiset.ipynb` — Original preprocessing workflow.
- `comisett2.ipynb` — Column dropping and feature analysis.
- `feature_engineering.ipynb` — Feature extraction and transformation.

## Data
The dataset and generated intermediate files are not included in this repository because of their size. Input and output paths may need to be configured for the execution environment.
